# Unmount

| Method                | Command                       |
| --------------------- | ----------------------------- |
| Foreground process   | Press `Ctrl+C`                |
| Manual (Linux)        | `fusermount3 -u /tmp/mirror`  |
| Manual (macOS)        | `umount /tmp/mirror`          |
| Force unmount         | `fusermount3 -uz /tmp/mirror` |
